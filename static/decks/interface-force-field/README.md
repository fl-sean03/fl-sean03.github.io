# Interface Force Field: From atoms to evidence

Open `index.html` directly or serve this directory as static files. Arrow keys and horizontal swipes change slides; N toggles notes; P enters presentation mode. Slides 6, 14 and 23 open silent MP4 companions. The media library supplies GIF and PNG alternatives. Readable notes include exact equation and table equivalents.

`downloads/iff-visual-showcase.pptx` contains 35 slides with editable text, diagrams, a results table/chart and three embedded MP4s. The PDF and SVG slides are static alternatives. `presenter-notes.md`, `citation-license-manifest.json` and `LICENSE-ATTRIBUTION.md` retain scientific scope, sources and reuse terms.

Structures are source-derived ideal constructions; motion is illustrative. Published results were not rerun. The IFF Agent section explains its implemented workflow and separate model families; it establishes no new accepted parameter package. Source mechanical repeatability is distinct from accuracy against experiment.

Original assets receive no additional reuse license. Third-party licenses and attribution remain applicable. Video playback depends on the presentation application or browser; static alternatives preserve the explanation.

`source/` contains authoring scripts and data; see `SOURCE-REBUILD.md` for reproduction steps and dependencies.
