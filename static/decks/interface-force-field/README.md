# Interface Force Field

This presentation introduces atomic interactions and molecular mechanics, then explains how the Interface Force Field connects material models with published measurements. Rhodium provides a worked example. Six published applications show how evidence differs across systems and properties.

Open `index.html` for the self-contained browser viewer. The editable PowerPoint and selectable-text PDF are in `downloads/`. Presenter notes, primary-source citations and rebuild instructions are included alongside them.

The figures are original calculations or teaching diagrams. Structures are idealized, the energy landscape is illustrative, and published results were not rerun. No private lecture material is distributed.
